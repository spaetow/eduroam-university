# Welcome to eduroam University

## What is eduroam University?

eduroam University is a 'fake' university for demonstration or documentation purposes. It does not exist in real life. If you've found yourself at this page because you followed a link in some documentation on a different website, then it is possible that that documentation uses eduroam University as an example organisation.

## Why does eduroam University exist?

It stands in for any university or research institution on the planet when help collateral is generated, so that it can be re-used by all eduroam National Roaming Operators (NROs). There may be other purposes for eduroam University and its domain (eduroam.university) when opportunities present themselves, but this is currently its purpose.

## Why this name?

Sure, we could've chosen another name, but since eduroam is a service focused on the education and research sector, it is just fitting that the name eduroam University is used. Many NROs use example organisations (and they exist in their marketing, comms, and support collateral), but when something is made for everyone, having to redo videos several times just to take account of such example organisations is more time consuming. Using the eduroam University name makes it clear it's just that, an example.
